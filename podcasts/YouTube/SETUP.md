# YouTube Playlists Setup Guide

Quick guide to get the YouTube Playlists feature running.

## Prerequisites

- Xcode 15+
- iOS 17+ target
- Google Cloud account

## Setup Steps

### 1. Configure Google Cloud Console

1. Navigate to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project or select an existing one
3. Enable **YouTube Data API v3**:
   - Go to "APIs & Services" → "Library"
   - Search for "YouTube Data API v3"
   - Click "Enable"

### 2. Create OAuth 2.0 Credentials

1. Go to "APIs & Services" → "Credentials"
2. Click "Create Credentials" → "OAuth 2.0 Client ID"
3. If prompted, configure the OAuth consent screen first:
   - User Type: External (or Internal if using Google Workspace)
   - App name: Pocket Casts
   - User support email: Your email
   - Developer contact: Your email
   - Scopes: Add `https://www.googleapis.com/auth/youtube.readonly`
4. Back in "Credentials", create OAuth client:
   - Application type: **iOS**
   - Name: Pocket Casts iOS
   - Bundle ID: `au.com.shiftyjelly.podcasts`
5. Click "Create"
6. **Copy the Client ID** (looks like: `123456789.apps.googleusercontent.com`)
7. **Copy the Client Secret** (looks like: `GOCSPX-abcdefghijklmnop`)

### 3. Update Info.plist

Open `podcasts/podcasts-Info.plist` and update these keys:

```xml
<key>YouTubeOAuthClientID</key>
<string>YOUR_CLIENT_ID.apps.googleusercontent.com</string>

<key>YouTubeOAuthClientSecret</key>
<string>GOCSPX-YOUR_CLIENT_SECRET</string>

<key>YouTubeOAuthRedirectURI</key>
<string>com.googleusercontent.apps.YOUR_CLIENT_ID:/oauth2redirect/google</string>
```

Also update the URL scheme (search for "GoogleSignIn" in the file):

```xml
<dict>
    <key>CFBundleTypeRole</key>
    <string>Editor</string>
    <key>CFBundleURLName</key>
    <string>GoogleSignIn</string>
    <key>CFBundleURLSchemes</key>
    <array>
        <string>com.googleusercontent.apps.YOUR_CLIENT_ID</string>
    </array>
</dict>
```

**Important**: Replace `YOUR_CLIENT_ID` with the actual client ID from Google Cloud Console (the numbers before `.apps.googleusercontent.com`).

### 4. Build and Run

1. Open the project in Xcode
2. Select a simulator or device
3. Build and run (⌘R)
4. Navigate to Profile tab
5. Tap "YouTube Playlists"
6. Tap "Sign In with Google"
7. Authenticate with your Google account
8. Browse your playlists!

## Common Issues

### "The operation couldn't be completed. (com.apple.AuthenticationServices.WebAuthenticationSession error 1.)"

**Cause**: OAuth redirect URI doesn't match the URL scheme.

**Solution**: 
1. Check that `YouTubeOAuthRedirectURI` in Info.plist matches: `com.googleusercontent.apps.YOUR_CLIENT_ID:/oauth2redirect/google`
2. Check that the URL scheme in `CFBundleURLSchemes` matches: `com.googleusercontent.apps.YOUR_CLIENT_ID`
3. Make sure both use the same client ID

### "Authorization Error: redirect_uri_mismatch"

**Cause**: The redirect URI in the app doesn't match what's configured in Google Cloud Console.

**Solution**:
1. Go to Google Cloud Console → Credentials → Your OAuth Client
2. Verify the iOS Bundle ID is `au.com.shiftyjelly.podcasts`
3. The redirect URI is automatically generated by Google for iOS apps
4. Make sure your `YouTubeOAuthRedirectURI` follows the pattern: `com.googleusercontent.apps.CLIENT_ID:/oauth2redirect/google`

### "API key not valid. Please pass a valid API key."

**Cause**: YouTube Data API v3 is not enabled, or credentials are incorrect.

**Solution**:
1. Verify YouTube Data API v3 is enabled in Google Cloud Console
2. Check that you copied the full Client ID (including `.apps.googleusercontent.com`)
3. Verify the Client Secret is correct

### "You are not signed in to YouTube"

**Cause**: OAuth flow failed or tokens are not stored.

**Solution**:
1. Sign out and try again
2. Check Keychain has permissions to store data
3. Review Xcode console for detailed error messages

### Playlists Don't Load

**Cause**: API quota exceeded or network issue.

**Solution**:
1. Check Google Cloud Console → APIs & Services → YouTube Data API v3 → Quotas
2. Verify network connectivity
3. Check Xcode console for API error messages

## Security Notes

- **Never commit secrets**: The Client Secret in Info.plist should never be committed to version control
- **Use environment variables**: For production, consider using Xcode build configurations to inject secrets
- **Add to .gitignore**: Consider adding `*-Secrets.plist` pattern to ignore sensitive configuration

Example `.gitignore` entry:
```
# OAuth secrets
podcasts/YouTubeOAuth-Secrets.plist
```
